Honest scheduler boundary

This is a lightweight in-process scheduler backed by SQLite, not an always-on hosted worker. Hosting sleep, restarts, multiple uncoordinated replicas, or missing provider credentials can delay or fail work. Inspect each generated task; NOVA will not invent goals or represent a planned run as completed.
