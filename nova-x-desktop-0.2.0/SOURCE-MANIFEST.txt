Excluded: generated caches, local databases/workspaces, credentials, and built release binaries.
Build instructions: README.md, docs/NATIVE_DESKTOP.md, and docs/UNIFIED_OS.md.

Notes:
  * The cognition layer (§70–§89) lives in nova/cognition/ and is documented in
    docs/COGNITION.md, which states per-mechanism what is implemented, what is
    partial, and what is deliberately absent. Its evaluation suite is run with
    `python -m nova.cognition` (offline, deterministic, zero provider calls) and
    its state is persisted in seven cognition_* / intelligence_eval_runs tables
    created by nova/db.py.
  * The §90–§115 modular local platform stack is coordinated by
    nova/platform_service.py and documented in docs/PLATFORM_ARCHITECTURE.md,
    docs/EXTENSION_SDK.md, and docs/RELEASE_CHECKLIST.md. The 18-case §114
    integration matrix lives in tests/test_integration_matrix.py.
  * The §116–§148 Universal Creation Engine lives in nova/creation/ (with tool
    bindings in nova/tools/creation.py and native Qt studio UI in
    nova/desktop/app.py), documented in docs/CREATION_ENGINE.md and verified by
    `python -m nova.creation` (`nova-uce-v1`, 8 end-to-end cases) and
    tests/test_creation_engine.py.
  * The §1–§27 Unified Universal AI Operating System is unified by
    nova/unified_os.py, nova/memory_hub.py, nova/desktop_control.py,
    nova/self_improvement.py, optional local Ollama support in
    nova/model_providers.py, the 12-page native Qt Control Center in
    nova/desktop/app.py, and the 18-check acceptance suite in nova/acceptance.py
    (`python -m nova.acceptance` and tests/test_unified_os_acceptance.py),
    documented in docs/UNIFIED_OS.md.
  * The §149–§164 System Access, Hardware Intelligence, Resilience, Segmented
    Screen Studio, Observability, and Authorized OpenSSH/Node subsystem lives in
    nova/system_access/ and nova/tools/system_access.py, documented in
    docs/SYSTEM_ACCESS.md and verified by `python -m nova.system_access.acceptance`
    and tests/test_system_access_expansion.py.
  * The §165 Dark Web, Tor Network, and Advanced Internet Intelligence Module
    lives in nova/privacy_intel/ and nova/tools/privacy_intel.py, documented in
    docs/PRIVACY_INTEL.md and verified by `python -m nova.privacy_intel.acceptance`
    (15 acceptance checks) and tests/test_privacy_intel_module.py.
  * The §1–§11 Corrected Master Hybrid Architecture (Locally Hosted Autonomous AI
    Platform Powered by Cloud Frontier Intelligence) lives in nova/hybrid_cloud/,
    documented in docs/CORRECTED_MASTER_ARCHITECTURE.md and verified by
    `python -m nova.hybrid_cloud.acceptance` (15 acceptance gates) and
    tests/test_corrected_master_architecture.py.
  * The §181–§200 Advanced Kali Linux Intelligence, Application Mastery, and
    Universal Software Integration Layer lives in nova/kali_intel/ and
    nova/tools/kali_intel.py, documented in docs/KALI_INTELLIGENCE_LAYER.md and
    verified by `python -m nova.kali_intel.acceptance` (18 acceptance checks)
    and tests/test_kali_intelligence.py.
  * The §201–§220 Autonomous Cybersecurity, Vulnerability Research, and Security
    Engineering Division lives in nova/cyber_division/ and
    nova/tools/cyber_division.py, documented in docs/CYBERSECURITY_DIVISION.md and
    verified by `python -m nova.cyber_division.acceptance` (18 acceptance checks)
    and tests/test_cyber_division.py.
  * The §221–§235 Autonomous Software Acquisition, Environment Management, and
    Universal Migration Engine lives in nova/acquisition_migration/ and
    nova/tools/acquisition_migration.py, documented in
    docs/ACQUISITION_AND_MIGRATION.md and verified by
    `python -m nova.acquisition_migration.acceptance` (20 acceptance checks) and
    tests/test_acquisition_migration.py.
  * Pytest configuration lives only in pyproject.toml ([tool.pytest.ini_options]);
    the duplicate pytest.ini that used to shadow it has been removed.
  * Lint configuration lives in pyproject.toml ([tool.ruff]).
  * CI lives at the repository root: .github/workflows/ci.yml (outside this bundle).
  * releases/*.deb is a build artifact produced by scripts/build_deb.sh and is not
    part of the source bundle.
