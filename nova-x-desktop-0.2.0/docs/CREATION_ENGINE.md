# NOVA X Universal Creation Engine (§116–§148)

NOVA X includes a modular, low-resource-aware **Universal Creation Engine** (`nova/creation/`) inside the native Kali Linux desktop application (`nova/desktop/`) and local platform service (`nova/platform_service.py`).

Websites, mobile prototypes, games, 3D models, videos, documents, and datasets generated by the engine are **deliverables inside scoped project workspaces**; they never replace NOVA's native PySide6 desktop interface (§116, §124).

## Domain Honesty & Safety Invariants

1. **Real files and verified execution only (§116, §138):** File existence alone never passes QA. Code is syntax-checked and run through `pytest`; 3D meshes are checked for watertight manifold edges, positive bounding volume, and zero degenerate triangles; PNG/SVG/WAV/AVI/DOCX/XLSX/PDF/SQLite outputs are header- and structure-validated.
2. **Preserved editable sources (§118C, §120, §122, §131, §132):** Editable source files (`.svg`, `.scad`/parametric `.py`, `.md`, `.sql`, `.csv`) are always retained alongside raster/binary exports. Format conversion and repair never overwrite source files without authorization and explicitly report any lossy information loss.
3. **Domain-specific truthfulness:**
   - **Creative writing vs. factual reports (§118B):** Fictional narratives are labeled `creative_fiction`, never factual reporting.
   - **Data science, ML & simulations (§118E, §126, §128, §142):** Synthetic or procedural runs are labeled `illustrative_simulation_or_synthetic` with recorded random seeds, holdout metrics, and small-sample warnings—never presented as real-world experimental observations.
   - **Video & media (§121):** Automated storyboard/frame-sequence assembly is clearly distinguished from unconfigured external neural video generation models.
   - **3D & hardware engineering (§122, §127):** Parametric models, schematics, BOMs, and MCU logic include explicit disclaimers that structural, electrical, manufacturing, and medical safety require qualified engineering validation, and `physical_hardware_tested` is reported `False` unless physical interfaces are configured and authorized.
   - **Education & business (§129, §130):** Primary user notes are separated from supplementary explanations; financial scenarios state explicit mathematical assumptions and never fabricate customer validation or market guarantees.
   - **Asset licensing (§135):** Externally sourced assets with unknown or copyrighted licenses are flagged `reusable = False`.
   - **Zero silent installs (§136, §147):** Missing optional external tools (`ffmpeg`, `blender`, `openscad`, `pandoc`, `libreoffice`) are reported honestly with authorization-gated setup plans; NOVA never silently installs system packages or modifies APT repositories.

## Running the §148 Universal Creation Capability Test

```bash
cd nova-x-desktop-0.2.0
python -m nova.creation
```

The `nova-uce-v1` suite executes **8 end-to-end demonstrations** in an isolated workspace:
1. `01_software_desktop_utility` — Tested & packaged Python software utility (`pytest` + handover `.tar.gz`).
2. `02_visual_design_editable_asset` — Editable SVG vector source + RGBA PNG render + thumbnail + palette metadata.
3. `03_media_short_video_assembly` — Storyboard + PCM WAV audio + SRT subtitles + playable RIFF AVI & animated GIF preview.
4. `04_data_analysis_and_visualization` — Reproducible analysis script, metrics JSON, SVG/PNG chart, and provenance report.
5. `05_3d_parametric_model_validation` — Parametric generator + watertight manifold `.stl`/`.obj` mesh validation + orthographic render.
6. `06_automation_authorized_workflow` — Integration connector + validated & executed `WorkflowEngine` DAG run.
7. `07_new_capability_isolated_extension` — Candidate plugin generated and verified inside `PluginManager.stage_candidate` sandbox without enabling untrusted code automatically.
8. `08_tool_failure_reporting_and_recovery` — Unconfigured external binary failure reported transparently, recovered via verified local fallback, plus retain/revert checkpoint verification.

Passing these 8 cases verifies the demonstrated creation pipelines and deliberately sets `all_creation_domains_claimed_universal = False` (§148).
